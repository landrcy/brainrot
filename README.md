# Brainrot Night Council 🌙

Six-page Italian brainrot site. Pure HTML/CSS/JS — no CDNs, no external assets, all links relative. Each page has its own inline CSS and its own interaction so no two pages share a template.

## Open locally
Double-click `index.html`, or `python3 -m http.server` here → http://localhost:8000

## Pages
| Page | Character | Look | Interaction |
|---|---|---|---|
| `index.html` | Tung Tung Tung Sahur | carved woodgrain, Impact poster type, scrolling TUNG ticker, frozen 3 AM clock | wooden drum with persistent bang counter + ranks, live 3 AM patrol map (open a door and he comes in) |
| `bombardiro.html` | Bombardiro Crocodilo | green phosphor cockpit HUD, scanlines, gauges | moving target bombing run, ammo/reload (R), barrel roll (B), mission log, classified dossier |
| `tralalero.html` | Tralalero Tralala | neon ocean dance club | sneaker stomps, dress code, DROP THE BEAT ritual |
| `cappuccina.html` | Ballerina Cappuccina | elegant café ballet | heart-latte / pirouette ritual, soft may sit corner |
| `patapim.html` | Brr Brr Patapim | frost ritual temple | frost ritual counter (stick) |
| `verity.html` | Verity (NEW) | cream paper dossier, rotating seal, red/green rubber stamps | True/False claims desk with grading, click-to-stamp sheet, nightly audit checklist, footer lore promoted to Standing Verdicts |

## Shared files
- `base.css` — minimal: reset, nav, toast, popups only
- `styles.css` — legacy shared styles (still used by tralalero)
- `main.js` — nav highlight, Web Audio sfx (no sound files), `BR` helper API, `[data-bang]` compat, Easter eggs: type **sahur** or **verity** on any page; console message
