# Brainrot Night Council 🌙

Multi-page Italian brainrot site. Pure HTML/CSS/JS, no external dependencies or CDNs.

## Open locally
Double-click `index.html`, or run `python3 -m http.server` in this folder and visit http://localhost:8000.

## Pages
- `index.html` — Tung Tung Tung Sahur (bang the log)
- `bombardiro.html` — Bombardiro Crocodilo
- `tralalero.html` — Tralalero Tralala
- `cappuccina.html` — Ballerina Cappuccina
- `patapim.html` — Brr Brr Patapim
- `styles.css`, `main.js` — shared styles and click/sound interactions (Web Audio, no sound files)

## Publishing
fish site will publish this folder to GitHub Pages (static, all paths relative — works from repo root or subpath).
